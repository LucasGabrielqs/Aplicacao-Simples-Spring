# Atividade Spring Boot - Endpoints Simples

## Descrição
Este projeto foi desenvolvido como parte da atividade da disciplina de Desenvolvimento de Sistemas Distribuídos, com o objetivo de **praticar o uso do Spring Boot e a criação de endpoints REST**.

A aplicação **não utiliza banco de dados**, apenas retorna mensagens simples para testes.

---

## Funcionalidades

A aplicação possui **dois endpoints principais**:

### `/hello-world`
- **Método:** GET
- **Descrição:** Retorna uma mensagem de boas-vindas.

### `/personalized-message`
- **Método:** GET
- **Descrição:** Retorna uma mensagem personalizada com o nome.


---

## Objetivo do projeto
Concluir a atividade prática da matéria e testar os conhecimentos adquiridos sobre **Spring Boot** e **REST API**.
